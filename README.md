# texttextstext · 哲學的慰藉

Tufte CSS 風格的哲學對話與文本排版設計器。

## 設計原則

- **排版**: 參考 Edward Tufte 的信息設計原則
- **字體**: ET Book (英文) + 思源宋體 (中文繁/簡)
- **配色**: 高對比度，紙張色背景 (#fffff8)，避免「糊」感
- **交互**: 減去不必要的操作，保留核心功能

## 文件結構

```
.
├── index.html      # 入口導航 (Tufte 風格)
├── sirius.html     # 哲學對話 Agent
├── designer.html   # 文本排版設計器 (簡化版)
└── README.md
```

## 模塊一：Sirius 對話

- 七種哲學人格：Sirius / 蘇格拉底 / 伊壁鳩魯 / 塞內加 / 蒙田 / 叔本華 / 尼采
- 自動情緒檢測切換
- 金句提煉與複製
- 一鍵跳轉設計器

## 模塊二：Designer 排版

**簡化後的功能：**
- 文本輸入（主文字 + 出處）
- 3 種字體：宋體 / 黑體 / 行書
- 4 種配色預設：墨紙 / 素白 / 松煙 / 赭石
- 4 種比例：1:1 / 3:4 / 4:3 / 9:16
- 3 種對齊：左 / 中 / 右
- 字號調節
- 高清 PNG 導出（支持 Retina 屏幕）

**去掉的功能：**
- 載體選擇（方巾/短袖/陶瓷杯等）
- 複雜的位置滑塊
- 自定義顏色選擇器

## 部署

純靜態頁面，可直接部署到 GitHub Pages / Netlify / Vercel。

```bash
# 本地預覽
python -m http.server 8080
```
